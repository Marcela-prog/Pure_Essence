# Pure Essence

Landing page de uma marca fictícia de cuidados pessoais, desenvolvida com foco em apresentação de produtos, identidade visual e experiência de compra no Front-End.

Projeto não comercial criado para praticar a construção de uma vitrine digital responsiva.

## Demonstração

Acesse a versão online:

[Visualizar Pure Essence](https://pure-essence-projeto.vercel.app/)

## Sobre o projeto

A Pure Essence é uma página de apresentação para uma marca fictícia de produtos de autocuidado e beleza. O projeto foi pensado para transmitir uma sensação de leveza, delicadeza e cuidado por meio de uma identidade visual com tons suaves, seções bem organizadas e navegação simples.

A página apresenta uma área principal de destaque, informações sobre a marca, uma seleção de produtos e um formulário de contato.

## Funcionalidades

- Navegação entre as seções da página;
- Menu responsivo para telas menores;
- Seção principal de apresentação da marca;
- Seção "Sobre nós";
- Vitrine com produtos, descrições e preços;
- Carrinho de compras visual;
- Contador de produtos adicionados ao carrinho;
- Exclusão de itens do carrinho;
- Notificação visual ao adicionar um produto;
- Formulário de contato com mensagem de confirmação;
- Layout responsivo para diferentes tamanhos de tela;
- Imagens e identidade visual voltadas ao segmento de autocuidado.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Vercel

## Como funciona

### Carrinho

Ao clicar no botão de adicionar um produto, o item é incluído no carrinho, o contador é atualizado e uma notificação aparece na tela. O usuário também pode abrir o painel lateral do carrinho e remover produtos individualmente.

### Formulário de contato

O formulário valida o envio no Front-End e exibe uma mensagem de confirmação. Como o projeto é uma demonstração de interface, os dados não são enviados para um servidor real.

### Menu responsivo

Em telas menores, o menu de navegação pode ser aberto e fechado pelo botão de menu.

## Como executar o projeto localmente

### Pré-requisitos

Você precisa ter um navegador moderno instalado. O projeto não possui dependências externas nem processo de build configurado.

### Instalação

Clone este repositório:

```bash
git clone https://github.com/Marcela-prog/Pure_Essence-projeto.git
```

Entre na pasta do projeto:

```bash
cd Pure_Essence-projeto
```

### Execução

Abra o arquivo index.html no navegador.

Também é possível abrir a pasta no VS Code e usar uma extensão como o Live Server durante o desenvolvimento.

## Observações

Este projeto é uma demonstração de Front-End. O carrinho não realiza compras, pagamentos ou persistência de dados, e o formulário de contato não envia mensagens para um serviço externo.

As imagens utilizadas na página são carregadas a partir de URLs externas do Unsplash.
